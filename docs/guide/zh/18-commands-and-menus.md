# 命令与菜单一览

## 命令

插件注册了以下命令，不会自动分配快捷键，可以在虎鲸笔记的快捷键设置里自己绑定。

| 命令 | 作用 | 斜杠命令 |
|---|---|---|
| 转为任务 | 把光标所在的块变成收集箱里的任务 | ✓ |
| 创建任务 | 打开创建任务窗口，新任务写进今天的日记 | ✓ |
| 提取任务 | 让 AI 从光标所在的块里识别出可执行的任务 | ✓ |

斜杠命令在输入 `/` 后的「今天干点啥」分组里。

## 编辑器工具栏

编辑器右侧工具栏里的「今天干点啥」按钮，打开或关闭插件面板。

## 任务操作菜单

打开方式：

- 任务块的块菜单
- 右键任务标签
- 点笔记中任务块前的状态图标（菜单最上面是六种状态）
- 右键插件面板中的任务卡片，或点卡片上的状态图标

| 菜单项 | 什么时候出现 |
|---|---|
| 状态 | 总是 |
| 跳过这次 | 重复任务，没有暂停、没有完成、不是最后一次 |
| 标记已回顾 | 设了回顾周期或指定回顾日、没有完成的任务 |
| 加入我的一天 / 移出我的一天 | 总是 |
| 新建子任务 | 没有完成的任务 |
| 拆分子任务 | 没有完成的任务 |
| 打开任务属性面板 | 总是 |
| 在任务全景图中查看 | 总是 |
| 放弃 | 总是 |

## 项目操作菜单

打开方式：

- 右键项目标签
- 右键插件面板中的项目行，或点项目行上的项目状态图标

| 菜单项 | 作用 |
|---|---|
| 项目状态 | 切换五种项目状态 |
| 放弃项目 | 移除项目标签，放弃项目里没完成的任务 |

## 块菜单

| 菜单项 | 作用 |
|---|---|
| 提取任务 | 让 AI 从这个块，或选中的多个块里提取可执行的任务 |
