# 安装与启用

需要虎鲸笔记 1.98.0 或更新的版本。

## 从插件市场安装

1. 打开虎鲸笔记的插件市场，搜索「今天干点啥」并安装。
2. 在「设置 → 插件」中启用。

## 下载 zip 安装

1. 在 [Releases](https://github.com/gowithmoon/orca-plugin-nextaction/releases) 页面下载 `orca-plugin-nextaction-v<版本号>.zip`。
2. 解压到用户文档目录下的 `orca/plugins` 中：
   - Windows：`C:\Users\<用户名>\Documents\orca\plugins`
   - macOS：`~/Documents/orca/plugins`
3. 确认解压后的路径是 `orca/plugins/orca-plugin-nextaction/`，文件夹里直接放着 `dist/`、`package.json` 等文件。
4. 重启虎鲸笔记，在「设置 → 插件」中启用它。

> [!IMPORTANT]
> 文件夹名必须是 `orca-plugin-nextaction`。虎鲸笔记用文件夹名识别插件，插件的设置和数据都按这个名字保存，改名之后就成了另一个插件。

## 第一次启用

插件会在当前笔记库里建好两个标签，并给它们加上插件需要的属性：

- 任务标签：界面语言是中文时默认为「任务」，英文时默认为「Task」。任务标签默认有状态、重要性、紧急度、工作量、开始日期、截止日期、上下文、备注、顺序执行、依赖、依赖模式、依赖延迟、所属项目等属性。
- 项目标签：中文时默认为「项目」，英文时默认为「Project」。项目标签有项目状态、目标、开始日期、截止日期、重要性、紧急度等属性。

若启用插件前笔记库里已经有同名标签，插件将直接使用并补上缺少的属性。若同名标签上已有的属性和插件需要的类型冲突时，插件将无法正常使用，需要在插件设置中更换标签名。

## 修改标签名

可以在「设置 → 插件 → 今天干点啥」里自定义任务标签名、项目标签名。

> [!WARNING]
> 不要直接在虎鲸笔记里给这两个标签改名或删除它们，可能导致旧任务无法识别。

## 停用与卸载

插件数据都存在笔记里：任务的属性在任务标签上，完成历史、重复规则、提醒、我的一天记录等存在任务块的块属性里。停用或卸载插件后，这些数据原样留在笔记中，随笔记同步和导出；重新启用后继续可用。
