# 重复任务与提醒

## 重复任务

每周交周报、每月交房租、每三个月理一次发，这类事设成重复任务。重复任务始终是同一个块，每完成一次，插件就把它的日期修改到下一次，不会生成新块。

### 设置重复规则

在任务属性面板里点「重复」，打开设置窗口：

1. 选周期：每 N 天、周、月、年，或每 N 个工作日。
2. 按需要指定哪几天需要重复：每周的周几，每月的几号、最后一天或第几个周几，每年的几月几日，都可以多选。
3. 选下次重复日期计算模式：
   - 按固定日程：从原定日期往后算，不管哪天完成。比如每周一交周报，周三才标记为完成，下次还是下周一。
   - 按完成日期：从实际完成那天往后算。比如每三个月理一次发，哪天理的就从哪天算。
4. 结束条件：到某天为止，或重复几次。

窗口下方会预览「如果今天完成，下次是哪天」，确认无误再保存。

> [!TIP]
> 重复任务最好设上截止日期或开始日期，插件按它们往后挪。只设截止日期时，任务完成后会马上重新出现在下一步行动里；想到时候才出现，再设一个开始日期。

### 完成之后

在插件里把重复任务改成已完成时，插件会：

- 记录一条完成记录，保存在块属性中。
- 把截止日期（和开始日期）挪到下一次，状态回到待开始。
- 把它已完成的子任务一起改回待开始，日期跟着挪同样的天数。

到了结束条件，最后一次完成后任务就保持已完成，不再重复。

### 跳过、暂停与未自动重复

- 跳过：这次不做，直接到下一次。
- 暂停：暂停期间就是普通任务，完成后不会自动重复，规则保留。
- 未自动重复：在虎鲸笔记的标签属性里直接把重复任务改成已完成，插件会无法感知到，卡片上会提示「未自动重复」。打开任务属性面板，点击「安排下一次」即可修正。

## 提醒

提醒在设定的时刻弹出系统通知，一个任务可以有多个提醒。

### 设置提醒

在任务属性面板里点「提醒」，打开设置窗口：

- 快捷添加：截止日期当天、前 1 天、前 3 天、前 7 天，开始日期当天、前 1 天。时刻用设置里的「默认提醒时间」（默认 9:00），可以修改。
- 自定义：选具体的日期和时刻。

提醒和任务的日期是独立保存的，这意味着选完快捷选项就换算成具体时刻，之后再改截止日期，提醒不会跟着变。
