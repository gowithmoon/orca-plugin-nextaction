# 任务与状态

## 什么是任务

被打上任务标签的块就是一个任务。

一个块可以同时带任务标签和其他标签。其他标签就是任务的「标签」属性，见[任务属性](05-task-properties.md#标签)。

## 六种状态

每个任务在任一时刻恰好处于一种状态：

| 状态 | 含义 |
|---|---|
| 收集箱 | 新任务默认状态，需要进一步完善属性 |
| 待开始 | 确定要执行的任务，还没开始 |
| 进行中 | 任务已开始执行，尚未完成 |
| 等待中 | 需要等待满足外部条件，自己暂时无法推进 |
| 将来/也许 | 现在不会做，但未来可能要做 |
| 已完成 | 任务已完成 |

如果在编辑器内直接修改任务状态属性导致插件无法识别，会按照收集箱状态处理。

## 修改任务状态

以下几个地方都可以修改状态，效果相同：

- 点笔记中任务块前的状态图标。
- 在任务操作菜单里选「状态」。任务操作菜单在任务块的块菜单里，右键任务标签也能打开。
- 在插件面板里点卡片的状态图标，或右键卡片。
- 在任务属性面板里改「状态」。

在插件里把任务改成已完成时，插件会：

- 在任务块的块属性中新增一条完成记录，用于统计、回顾和依赖延迟。
- 普通任务：清除它的提醒。
- 重复任务：状态回到待开始，根据重复规则修改时间、子任务等。

> [!NOTE]
> 状态也是任务标签上的普通属性，可以在虎鲸笔记的标签属性里直接改。这样改不会留下完成记录，重复任务也不会安排下一次。建议仅在插件提供的入口里改状态。

## 放弃任务

决定不做一个任务时，放弃它：在任务操作菜单里选「放弃」，或者点任务属性面板里的「放弃任务」。放弃会：

- 移除任务标签，块留在笔记里，变回普通块。
- 丢弃插件为它记下的数据：完成历史、重复规则、提醒、回顾计划、我的一天记录。
- 清除其他任务指向它的依赖。

它的子任务不受影响，仍然是任务。放弃不会二次确认，如果误操作按一次撤销就能全部恢复。

放弃不同于完成：完成表示做完了，会留下记录；放弃表示不做了，任务从此消失。

直接移除任务标签也会放弃任务，但不会清除完成历史、重复规则、提醒、回顾计划、我的一天记录等记录在块属性中的数据。
