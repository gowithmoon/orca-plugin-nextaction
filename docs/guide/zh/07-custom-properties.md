# 自定义属性

内置属性不够用时，可以给任务标签或项目标签加自己的属性，例如「委托给」「来源」「下发人」。

## 添加、修改和删除

自定义属性的定义只在虎鲸笔记里管理：打开任务标签或项目标签的页面，在它的标签属性里添加属性，设类型、默认值和选项。插件没有另外的管理入口。

- 添加自定义属性后，每个任务（或项目）都可以设置该属性的值。设置默认值后，新打上标签的块由虎鲸笔记填入默认值。
- 删掉属性定义时，所有任务（或项目）上的这一项连同值一起消失。

任务标签和项目标签的自定义属性互不相干。

## 在属性面板里编辑

任务的自定义属性显示在任务属性面板的「所属项目」下面，项目的显示在项目属性面板的最下面。每种类型有对应的输入方式。

## 能做什么，不能做什么

自定义属性只是记录，不影响下一步行动、阻塞、评分、提醒和回顾。

它们不能作为筛选和排序的条件。任务的自定义属性能被搜索到，例如给任务加了「委托给：张三」，搜「张三」就能列出委托给他的任务。项目的自定义属性只在项目属性面板里显示。

## 不显示的属性

以下属性不作为自定义属性显示：

- 名字以 `_` 开头的属性（虎鲸笔记的系统属性）。
- 和这个标签的内置属性同名的属性，中英文名都算。项目标签上的「工作量」不和任务的工作量冲突，会作为项目的自定义属性显示。
- JSON 类型和计算属性。
