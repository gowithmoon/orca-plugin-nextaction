# 回顾

GTD 的每周回顾，是定期把所有清单过一遍：收集箱清空了没有，有没有逾期的任务，项目都还在正常推进吗。回顾视图把这个过程拆成固定的几步，带你逐步检视任务。

## 完整回顾

在回顾视图里点「开始完整回顾」，依次进行以下几步：

| 步骤 | 内容 | 建议的操作 |
|---|---|---|
| 收集箱 | 收集箱里的任务 | 逐个澄清，设置任务属性，拆分子任务 |
| 回看过去 | 上次完整回顾以来完成和跳过的任务，以及加入过我的一天、至今没完成的任务 | 审视已完成的任务是不是真的完成了，之前做过的任务有没有完成 |
| 逾期任务 | 已过截止日期、还没完成的任务 | 已完成的立即修改状态，确实逾期的反思原因，根据实际情况调整截止日期，或者立即去做 |
| 未来 7 天到期 | 未来 7 天内到期的任务 | 耗时久的工作要提前开始 |
| 下一步行动 | 现在能做的任务 | 有没有还不能开始的任务，了解当前可以做哪些任务 |
| 等待中 | 处于等待中的任务 | 外部条件是否满足，是否需要单独推动 |
| 项目 | 所有没完成的项目，以及已完成但还有任务没做完的项目 | 审视项目是否在正常推动，有无阻塞点 |
| 将来/也许 | 暂时不做的任务 | 是否已经可以开始做了，是否确定不再做了 |
| 需要回顾的任务 | 到了回顾日子的任务 | 想一想这个任务需要回顾哪些东西，标记已回顾、修改回顾周期 |
| 小结 | 当前情况的汇总 | 完成回顾，AI生成回顾小结 |

步骤之间可以用「上一步」「下一步」切换，也可以点步骤栏直接跳到任意一步。不必每一步都看。

## 单个任务的回顾计划

有些任务需要隔一段时间看一眼，比如一个长期的学习计划、一份要定期更新的文档。给它设上回顾计划，到回顾时间后就会出现在「需要回顾的任务」里。

在任务属性面板里点「回顾」：

- 回顾周期：每 N 天、周或月回顾一次。按周可以指定周几，按月可以指定几号或最后一天。
- 指定回顾日：只在某一天回顾一次。

看过之后点「标记已回顾」，下一次的日子从今天重新计算。

也可以在回顾视图里点「只看需要回顾的任务」，单独处理它们而不做完整的回顾。
