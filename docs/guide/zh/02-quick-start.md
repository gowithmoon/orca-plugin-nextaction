# 五分钟快速上手

## 1. 建第一个任务

三种方式任选其一：

- 光标放在一个块里，输入 `/`，选「今天干点啥」下的「转为任务」，这个块会被打上任务标签，进入收集箱。
- 输入 `/`，选「创建任务」，在弹窗里写下任务名称，按 Enter。新任务追加到今天日记的末尾，进入收集箱。
- 直接给块打上任务标签（默认叫「任务」），效果和转为任务相同。

任务块前会出现一个状态图标，收集箱是灰色的收件箱图标。

## 2. 打开插件面板

点编辑器右侧工具栏里的「今天干点啥」按钮，插件面板在当前激活面板旁打开，再点一次会关闭。

面板顶部是视图导航，可以切换视图，默认视图为「下一步行动」。新建的任务为收集箱状态，表示该任务仅记录、未确定要执行，所以下一步行动是空的。

## 3. 澄清任务

1. 在导航里点「收集箱」。
2. 点任务卡片，打开任务属性面板。
3. 把状态改成「待开始」，按需要填重要性、截止日期等任务属性。

回到「下一步行动」，这个任务就会出现。下一步行动是插件根据任务状态以及各项属性值自动计算出来的：处于待开始或进行中、没有被别的任务阻塞、已到开始日期的任务都会出现在这里，按优先级评分从高到低排列。

## 4. 执行任务

在笔记或插件面板中点击任务状态图标，在弹出的菜单里选一个状态。开始做时改成「进行中」，做完改成「已完成」。

任务块的块菜单、右键任务标签、右键插件面板中的卡片，都能打开任务操作菜单，可以快速修改状态、加入我的一天、新建子任务、打开任务属性面板、放弃该任务等。

理论上所有修改都可以用 Ctrl+Z（macOS 上是 ⌘+Z）撤销。

## 5. 绑定快捷键

插件不自动分配快捷键。在虎鲸笔记的快捷键设置里搜索「转为任务」「创建任务」「提取任务」，给它们绑定自己的快捷键。
