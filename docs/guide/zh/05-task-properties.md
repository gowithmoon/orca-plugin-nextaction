# 任务属性

任务的属性可以在任务属性面板里查看和编辑。点插件面板里的任务卡片，或者在任务操作菜单里选「打开任务属性面板」，都可以打开。

属性面板从上到下依次是：

| 属性 | 说明 |
|---|---|
| 状态 | 任务状态 |
| 阻塞原因 | 待开始、进行中的任务不是下一步行动时，列出原因。只读 |
| 重要性、紧急度、工作量 | 从低到高分为7个级别，参与优先级分数计算 |
| 开始日期、截止日期 | 任务的开始日期和截止日期，当前只精确到日期，不可以设置时间 |
| 重复、提醒、回顾 | 打开对应的设置弹窗 |
| 上下文、标签、备注 | 分类与补充说明 |
| 顺序执行、依赖、依赖模式、依赖延迟 | 任务之间的先后关系 |
| 所属项目 | 任务属于哪个项目 |
| 自定义属性 | 你在虎鲸笔记手动里给任务标签加的额外属性 |
| 阻塞、完成历史 | 当前任务阻塞了哪些任务、任务的完成记录。只读，有内容时才显示 |

## 重要性、紧急度、工作量

三项都分七档，默认都是第四档「一般」：

| 档 | 重要性、紧急度 | 工作量 |
|---|---|---|
| 1 | 极低 | 极小 |
| 2 | 很低 | 很小 |
| 3 | 较低 | 较小 |
| 4 | 一般 | 一般 |
| 5 | 较高 | 较大 |
| 6 | 很高 | 很大 |
| 7 | 极高 | 极大 |

- 重要性：这件事对你有多大价值。
- 紧急度：这件事的紧急程度。它和截止日期是分开的：截止日期由插件按日期计算，紧急度是你自己的判断。
- 工作量：完成它需要投入多少精力、时间。

三项都参与计算优先级分数，决定下一步行动的先后顺序。重要性和紧急度还会沿父任务和所属项目向下传播：给一个重要的父任务设了「很高」，它下面的子任务在计算优先级分数时也跟着提高，不必再逐个设置。传下来的值只影响评分，筛选和卡片上显示的是任务自己的值。评分的细节见[下一步行动](10-next-actions.md#评分)。

## 开始日期和截止日期

- 开始日期：最早哪天可以开始。这天之前，任务不会成为下一步行动（设置中可修改）。父任务、祖先任务和所属项目的开始日期同样约束它，会取这些日期中最晚的那一天。
- 截止日期：必须在哪天完成。这天过完仍未完成，任务就逾期了，卡片上的截止日期会标红。

插件里的「今天」从日界线开始算，默认是早上 5:00，可以在设置中修改。日界线为 5:00 时，凌晨 2 点仍算前一天：前一天截止的任务这时还没有标记逾期。

想让任务提前出现在下一步行动里，可以在设置里调大「开始日期预览天数」，见[下一步行动](10-next-actions.md#提前看到快要开始的任务)。

## 上下文

做这件事需要的场景条件，一个任务可以有多个上下文。比如你在家里和公司共用同一个笔记库，“召开项目启动会”只有在公司可以去做，此时可以添加一个“公司”上下文；“周末进行家庭大扫除”只有在家里可以做，此时可以添加一个“家里”上下文。

下一步行动和全部任务视图都能按上下文筛选，可以根据当前所处的场景来查看目前可以做什么任务。

## 标签

任务块上带的虎鲸笔记标签，任务标签和项目标签除外，只做只读展示，允许筛选。

插件只看块上直接打的标签：父任务和所属项目的标签不会传给它，标签之间的包含关系也不展开。

## 备注

任务的补充说明。
