# 任务全景图与统计

## 任务全景图

任务全景图把任务之间的关系画成一张图，从全局角度查看任务之间的关系，并进行快速调整。

### 怎么读全景图

- 每个任务是一张卡片。
- 项目是最外层的框，不属于项目的任务在「无项目」区域里。
- 框内第一个任务是父任务，子任务排在它下面。
- 顺序执行的父任务里，子任务横着排成一串，依次相连。
- 箭头表示依赖关系，从被依赖的任务指向在等它的任务。虚线表示依赖模式为“任一”，有依赖延迟时标记「+N天」。
- 日期冲突的箭头标黄，循环依赖标红。
- 下一步行动加强调，被阻塞的有阻塞标识，等待中和将来/也许淡化显示。

默认不画已完成的任务和孤立任务（不依赖任何任务，也不被任何任务依赖），顶部的「显示已完成」「显示无关系的任务」两个设置可以调整。

### 浏览

- 点一张卡片，高亮它的上下游，其余变淡；点空白处取消。
- 项目框和父任务框可以折叠。
- 用搜索框定位任务。在任务操作菜单里选「在任务全景图中查看」，也会跳到这里并定位到那个任务。
- 点任务名打开任务属性面板，点状态图标改状态，右键弹出任务操作菜单。

| 操作 | 鼠标、触控板 | 键盘 |
|---|---|---|
| 平移 | 滚轮，Shift + 滚轮横向；拖动空白处；按住空格或中键拖动 | |
| 缩放 | Ctrl（⌘）+ 滚轮，或双指捏合 | + / - |
| 适应窗口 | | F |
| 取消选中 | 点空白处 | Esc |
| 在卡片间移动焦点 | | Tab，Enter 打开任务属性面板 |

### 在图上调整关系

- 添加依赖：鼠标移到卡片上，右边缘出现连接点，从那里拖到另一个任务上，那个任务就开始依赖这一个。
- 删除依赖：点选一条箭头后按 Delete，或者右键箭头选「删除依赖」。
- 顺序执行：父任务框头上有开关。
- 依赖模式和依赖延迟：点任务入口处的图标修改。
- 移动任务：把卡片拖进另一个父任务框，成为它的子任务；拖到兄弟卡片之间，调整先后。
- 拖到项目框的空白处时，可以选「移动到项目块下」，或者「仅设置属性，不移动当前块」。
- 拖到「无项目」区域，任务就不再属于任何项目。

每次调整都可以撤销。会造成循环依赖的操作会被拒绝。
