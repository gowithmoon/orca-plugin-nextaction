# 项目

项目把一组任务归在一个想要的结果之下，比如「搬家」「年底旅行」「发布 2.0」。项目本身不是任务：它没有任务的状态和依赖，不会出现在下一步行动里，而是用项目状态和日期约束属于它的任务。

## 新建项目

给一个块打上项目标签（默认为「项目」），它就成了项目。

## 项目属性面板

项目的属性在项目属性面板里查看和编辑。在项目操作菜单里选「打开项目属性面板」，或者在项目详情里点日期、重要性、紧急度那一行或目标，都可以打开。在虎鲸笔记的标签属性里直接改也可以。

| 属性 | 说明 |
|---|---|
| 项目状态 | 规划中、进行中、暂停中、将来/也许、已完成 |
| 目标 | 怎样算做完，一段文字 |
| 开始日期、截止日期 | 项目的时间范围 |
| 重要性、紧急度 | 会传给项目里的任务，影响它们的评分，1最低，7最高 |
| 自定义属性 | 你在虎鲸笔记里给项目标签加的属性，见[自定义属性](07-custom-properties.md) |

项目名在笔记里改。面板顶部的项目名可以点，点了在笔记中打开项目块。每次修改都可以撤销。项目属性面板和任务属性面板可以同时打开。

## 项目状态

| 状态 | 含义 |
|---|---|
| 规划中 | 还在想怎么做，新项目的默认状态 |
| 进行中 | 正在推进 |
| 暂停中 | 已经开始，暂时停下等待外部条件满足 |
| 将来/也许 | 当前不做，未来可能要做 |
| 已完成 | 做完了 |

只有进行中的项目，里面的任务才会出现在下一步行动里。

改项目状态：右键项目标签，或者在插件面板里点项目的状态图标、右键项目行，都会弹出项目操作菜单。在项目属性面板里也能改。

## 任务属于哪个项目

- 任务写在项目块下面，就属于这个项目。这时任务的「所属项目」显示「来自所在位置」。在这里改选别的项目，任务就改属那个项目。
- 任务写在其他位置时，可以在任务属性面板的「所属项目」里指定。
- 父任务属于哪个项目，它的子任务也跟着属于哪个项目。这时子任务的「所属项目」显示「来自父任务」，不能单独修改。

一个任务只能属于一个项目。

## 项目视图

### 项目列表

所有项目按项目状态分组，每个项目一行，显示进度和需要你关注的信号：

- 进度：已完成任务的工作量之和，除以全部任务的工作量之和。将来/也许的任务和重复任务不计入。
- 缺少下一步行动：项目在进行中，却没有一个下一步行动，也没有在等待中的任务。
- N 天无进展：项目在进行中，已经 14 天以上没有完成过任务，也没有新建任务。
- 逾期：已超过项目的截止日期。

### 项目详情

点击项目列表后进入项目详情，上方显示项目的状态、日期、目标和进度（点日期那一行或目标打开项目属性面板），下方显示属于这个项目的全部任务，当前支持层级、看板、甘特图三种布局，默认布局支持在设置中配置。

**层级**：和全部任务视图一样的树形结构，支持筛选、搜索、排序、拖动。

**看板**：可以按状态分列，也可以按根任务（项目里最上层的任务）分列。

- 按状态分列时，把卡片拖到另一列就会修改任务状态。
- 按根任务分列时，每个根任务一列，把卡片拖到另一列表示移动到对应的根任务下面。
- 拖到一张卡片上，成为它的子任务。
- 卡片上显示子任务的完成数，展开可以看到全部后代任务。

**甘特图**：以甘特图形式展示项目下的所有任务，用于规划任务排期、查看当前的进展。

- 拖动横条中间整体挪动日期，拖两端只改开始或截止日期。
- 只有一个日期的任务，缺的日期会借用项目的日期，用虚线表示。
- 没有任何时间属性的任务放在底部的「待排期任务」里，拖到图上可设置起止日期，默认一周。
- 依赖以箭头形式展示。一个任务的开始日期早于它依赖的任务的截止日期时，箭头标红，表示日期冲突。
- 顶部可以切换日、周、月三种刻度。

### 在项目中创建任务

在项目详情里点「创建任务」，或者在回顾的「项目」一步为某个项目创建任务，窗口的「所属项目」上方多一个「位置」：

- **项目末尾**（默认）：新任务成为项目块的最后一个子块，项目是页面时成为页面的最后一个顶层块。任务靠所在位置属于这个项目，「所属项目」显示项目名称和「来自所在位置」，不能修改。
- **今日日记**：新任务写进今天的日记，「所属项目」预填当前项目，可以改选或清空。

每次打开窗口，位置都回到「项目末尾」。窗口打开期间项目被放弃或删除时，选「项目末尾」不会创建任务，窗口保留已填内容，可以改选「今日日记」再创建。

## 放弃项目

在项目操作菜单里选「放弃项目」。插件会移除项目标签，**放弃项目里所有没完成的任务**，已完成的任务保留。会先弹确认框说明有几个任务受影响，可以撤销。
