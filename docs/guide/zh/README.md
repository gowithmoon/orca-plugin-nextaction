# 今天干点啥 用户手册

今天干点啥（NextAction）是虎鲸笔记（Orca Note）的 GTD 任务管理插件。任务就是笔记里的块，插件读取它们，算出此刻能做的事，并提供我的一天、项目、回顾等视图。

第一次使用，按顺序读完第一、二部分即可上手；之后按需查阅。
