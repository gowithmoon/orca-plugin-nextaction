# 插件面板

插件面板是插件的主界面，包含GTD任务生命周期的各个视图。

## 视图导航

面板顶部是视图导航，依次为：

| 视图 | 用途 | 导航数字含义 |
|---|---|---|
| 下一步行动 | 此刻能做的任务，按评分降序 | 下一步行动的个数 |
| 我的一天 | 今天计划做的任务 | 无 |
| 收集箱 | 还没澄清的任务 | 收集箱里的任务数 |
| 全部任务 | 以树形结构展示所有任务 | 无 |
| 项目 | 项目列表与项目详情 | 无 |
| 任务全景图 | 任务之间的关系图 | 无 |
| 回顾 | 引导式回顾当前任务 | 需要回顾的任务数 |
| 统计 | 展示任务统计数据 | 无 |

每次打开插件面板，都从「下一步行动」开始。

## 任务卡片

插件面板里的每个任务都以一张任务卡片呈现，展示任务状态、任务名称、重要性/工作量/紧急度等任务属性，点击右上角箭头可快速跳转到任务在笔记中的所在位置。

### 卡片上的操作

- 单击卡片：打开任务属性面板，根据面板宽度自动选择在右侧展示或弹窗展示。
- 单击状态图标：修改任务状态。
- 右键卡片：打开任务操作菜单。
- 按住卡片拖拽：在不同视图里含义不同，例如全部任务视图里是移动任务，我的一天里是排期。拖到编辑器中可以快速添加该任务的块引用到指定位置；松手时按住 Alt（macOS 上是 Option）则写入镜像块。
