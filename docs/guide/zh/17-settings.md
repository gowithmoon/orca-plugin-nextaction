# 设置一览

在「设置 → 插件 → 今天干点啥」中修改。

| 设置 | 默认值 | 说明 |
|---|---|---|
| 任务标签名 | 任务 | 识别任务的标签。首次启用时按界面语言取「任务」或「Task」。修改后插件会重命名这个标签，已有任务不受影响 |
| 项目标签名 | 项目 | 识别项目的标签。首次启用时按界面语言取「项目」或「Project」。修改方式同上 |
| 日界线 | 5:00 | 一天从这个时刻开始。影响「今天」的判断：逾期、开始日期、我的一天、重复和回顾等 |
| 默认提醒时间 | 9:00 | 提醒快捷选项（如截止日期当天、前 3 天）用的时刻 |
| 项目视图默认布局 | 层级 | 项目详情用层级、看板还是甘特图。修改后立即切换 |
| 我的一天默认布局 | 时间轴 | 我的一天用时间轴、列表还是四象限。修改后立即切换 |
| 开始日期预览天数 | 0 | 开始日期在这么多天以内的任务提前出现在下一步行动里，评分略低。填 0 到 14 |
| AI 说明块 | 空 | 笔记里一个块的 ID，在这个块里向 AI 介绍你的情况和习惯 |

## 修改标签名

新名字不能为空，也不能已经被别的页面或块占用，否则插件会把设置改回原来的名字并提示原因。

> [!WARNING]
> 只在这里改任务标签和项目标签的名字，不要在虎鲸笔记里直接给标签改名或删除标签。

## AI 说明块

每次调用 AI （拆分子任务、提取任务、AI 小结）时，这个块和它子块的内容都会一起发给虎鲸笔记里配置的 AI 服务。可以在里面写：

- 你的工作和生活情况，比如职业、常用的上下文。
- 你的偏好，比如「拆分子任务时最多拆 5 条」「小结写得简短些」。

在块上右键可以复制块 ID，填 `12345` 或 `((12345))` 都可以。不需要就留空。
