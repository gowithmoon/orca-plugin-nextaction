# 开始日期和截止日期只记日期，按逻辑日解释

开始日期和截止日期使用 Orca 日期属性的 `date` 子类型，只记年月日，不记时刻。开始日期表示从这个逻辑日开始（当天的日界线）任务才可以开始；截止日期表示在这个逻辑日结束（次日的日界线）之前完成，过了才算逾期。大多数任务只需要"哪一天"，这样写法最简单，含义也最直观。

## Considered Options

- `datetime` 子类型，并把 00:00 解释为"整天"：可以表达具体时刻，但实测发现界面上必须选时刻，不选就是 00:00，"只写日期"和"写了 00:00"在笔记里无法区分，只能约定 00:00 代表整天，0 点这个时刻就没法表达了（`docs/spikes/date-subtype.md`）。
- `datetime` 子类型，00:00 按字面理解：只写日期的任务实际截止在前一天晚上，与直觉相反。

## Consequences

- 属性类型创建后不能改（ADR 0008）。以后如果需要具体时刻（例如提醒），要另加属性，不能把这两个属性改成 `datetime`。
- 值在笔记里存为本地零点的绝对时刻。插件读取时只取本地年月日，写入时传本地零点；Orca 不会替代码截掉时刻。跨时区的设备上读出来可能差一天，暂不处理。
