# 自定义属性的定义只在 Orca 中管理

自定义属性就是用户在 Orca 自带的界面里给任务标签或项目标签加的属性。增删、改名、改默认值、改选项都在 Orca 里做，插件不提供管理入口，也不写属性定义。插件读取任务标签和项目标签上的定义：去掉 `_` 开头的系统属性、与这个标签的内置属性同名的（中英文都算），以及 JSON 和计算属性，剩下的都是自定义属性。插件在任务属性面板、项目属性面板里编辑它们的值；不按它们筛选，搜索时经块的 `text` 匹配到它们的值。唯一的例外是单选、多选属性：在面板里填入新值时，插件把这个值追加进选项，和上下文、标记一样。这只是追加选项，不改动定义的结构。

## Considered Options

- 插件提供"添加、删除自定义属性"的界面：被否决。Orca 自己的界面已经能做这些事，再加一套就多了一个入口；插件一旦开始写定义，就要为用户的属性承担 ADR 0008 的对齐、冲突、只增不改规则，以及删除时清理各任务上的值。

## Consequences

- 默认值由 Orca 在打标签时填入，转为任务、快速捕获天然带上，插件不读也不写（`docs/spikes/custom-properties.md`）。
- 删掉定义时，Orca 一并删掉各任务上的值，插件不做清理，也不会出现旧值复活（同上）。
- 任务标签和项目标签的定义各自独立，排除同名属性时只看本标签的内置属性：项目标签上的"工作量"是项目的自定义属性。一个块同时打了两个标签时，两边的自定义属性分别出现在任务属性面板和项目属性面板里。项目的自定义属性只出现在项目属性面板中，项目列表和项目详情不显示，也不搜索它们。
- 以后插件新增内置属性时，名字可能和用户已有的自定义属性撞上，按 ADR 0008 处理：类型一致就接管，类型不一致就让这个内置属性失效。新增内置属性前先检查名字。
