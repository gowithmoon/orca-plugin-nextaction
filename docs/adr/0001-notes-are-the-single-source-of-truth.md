# 笔记库是任务数据的唯一真相源

所有任务数据都存在笔记库里：用户需要看到、需要用 Orca 原生查询筛选的数据放任务标签的标签属性；插件内部使用的结构化数据（完成历史、重复规则、回顾计划等）放带插件前缀的块属性。`orca.plugins.setData` 只存放可丢弃、可重建的数据（缓存、UI 状态）。判断标准是：卸载插件后，任务数据仍然完整保留在笔记中，跟随笔记同步、导出、复制。

## Considered Options

- 把部分任务数据放进 `plugins.setData`，按块 ID 建索引：被否决。这样会出现同步状态不确定、块删除或复制后数据成为孤儿、导出笔记时数据丢失等问题。
