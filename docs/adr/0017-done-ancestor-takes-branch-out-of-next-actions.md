# 已完成的祖先任务让它的整个分支退出下一步行动

任务的任一祖先任务（任意一层）已完成时，这个任务不再是下一步行动，不论它自己处于什么状态、有没有阻塞。判断方式与搁置子树相同：沿祖先链向上看，不看中间祖先任务的其他状态。祖先任务改回其他状态后，后代任务按原有规则重新判断。收集箱里的父任务仍不约束子任务。本决定推翻 #51 的第 18 条用户故事（"父任务已完成不影响子任务"），参照 MyLifeOrganized（MLO）的激活判定："未完成且没有已完成的祖先"。

理由：用户把父任务标成已完成，意思是"这件事结束了"；它下面没做完的子任务，多半只是没顺手关掉，不该继续出现在下一步行动里。

## Considered Options

- 已完成的父任务不约束子任务（#51 第 18 条用户故事，第五步的做法）：被否决。日常使用中，关掉一个项目后，它下面的残留子任务还在下一步行动里冒出来。
- 标完成父任务时，一并完成或提示完成全部后代任务：不在本步做。它是一次额外的写入，会改写用户没有动过的任务；残留的清理留给回顾（第九步）。

## Consequences

- 没完成的后代任务仍留在全部任务视图的任务树里（已完成区的规则不变：只有整个子树都已完成的顶层任务才进入已完成区），用户需要时还能找到并处理它们。它们不算阻塞，任务树中不标阻塞标记。
- 任务图的条目记下最近的已完成祖先任务，供任务属性面板说明"为什么不是下一步行动"。
