# 项目不是任务，任务的归属由父任务优先决定

项目用一个单独的、插件管理的项目标签表达，项目块不是任务。项目有自己的五种项目状态（规划中、进行中、暂停中、将来/也许、已完成），以及目标、开始日期、截止日期、重要性、紧急度。项目块在任务关系中和普通块一样：父子任务、依赖、任务树都不因它改变（ADR 0003 不受影响）。项目只通过"所属项目"约束任务：项目不处于进行中、或还没到项目的开始日期时，属于它的任务不是下一步行动；项目的重要性和紧急度像祖先任务一样参与评分（ADR 0019）。

任务可以设定所属项目（块引用），把写在日记或别处的任务归到项目下。所属项目由父任务优先决定：从顶层任务沿祖先任务往下，第一个有归属的任务决定它和全部后代任务属于哪个项目；一个任务的归属先看它自己的设定，没有时看它在块层级上最近的项目块。一个任务至多属于一个项目，一个分支只属于一个项目。

理由：项目需要一套和任务不同的状态（规划中与暂停中在任务的六种状态里没有对应），两套状态叠在同一个块上时，用户在 Orca 里能把它们改得互相矛盾，插件无法判断以谁为准。归属关系不同于父子关系，项目不是任务，所以它不进入任务图的父子结构，子任务阻塞、顺序执行、任务树都不用合并两棵树。父任务优先保证同一个分支不会被拆到两个项目里：否则子任务所在的项目暂停时，子任务仍通过子任务阻塞卡住另一个项目里的父任务，两个项目的进度也各算半棵树。

## Considered Options

- 在任务标签上加一个"是项目"的属性：被否决。项目的字段会出现在每个任务上，项目也只能用任务的六种状态。
- 项目标签叠加在任务标签上，项目块同时是任务：被否决。项目有自己的状态后，一个块上会有两个状态。
- 由结构推导（有子任务的顶层任务就是项目）：被否决。无法表达暂时没有子任务的项目，而"缺少下一步行动"最需要抓住的正是它。
- 只按块层级归属，不提供所属项目属性：被否决。快速捕获的任务在日记里，只能靠移动块归入项目。
- 所属项目以最近的设定为准（子任务可以改到别的项目），或合并父子的设定（任务属于多个项目）：被否决，理由见上；参照 Linear 的 "only one project at a time"。

## Consequences

- 插件多管理一个标签：创建、对齐、接管、改名、冲突处理都复用任务标签的机制（ADR 0002、0008、0009）。
- 任务不能依赖项目，项目也没有依赖。
- 后代任务上被父任务覆盖的所属项目设定不生效，任务属性面板显示实际归属及其来源，不清除那条设定。
- 用户把两个标签打在同一个块上、或把项目放在任务或项目之下时，插件不拒绝，按上述规则处理：块同时是任务和项目；项目不嵌套，里层项目只是另一个项目。
- 放弃项目会放弃属于它的全部未完成任务（按块层级和按所属项目归属的都算），已完成的保留，作为一个撤销步骤。
