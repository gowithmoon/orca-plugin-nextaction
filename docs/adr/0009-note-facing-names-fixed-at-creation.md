# 写进笔记的属性名和选项名在创建时确定，之后不随语言变化

只有任务标签的名称可以由用户自定义。属性名（如"状态"）和选项名（如"收集箱"）在插件第一次创建它们时，按当时的界面语言（中文或英文）确定，之后不再改变。插件内部用固定的英文键（`inbox`、`todo` 等）表示它们，`infra` 的编解码层同时认识中文和英文两套名称。用户切换界面语言后，插件界面上的文字随之切换，已写进笔记的名称保持不变。

## Considered Options

- 让所有名称都可以在设置中修改：被否决。每个可改的名称都是一条数据迁移路径，设置页会很长，测试量也会成倍增加。
- 切换语言时整体迁移名称：被否决。切换语言不应触发批量修改用户数据，而且迁移中途失败会留下中英文混杂的状态。
