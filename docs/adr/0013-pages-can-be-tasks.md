# 页面可以是任务，日记和孤立块不是

Orca 中一切都是块，页面只是一个有别名的根级块，用户自然会把一个页面当作项目或大任务来用。所以"不是任务"的判断从"没有父块"放宽为"没有父块且没有别名"：页面带上任务标签就是任务；日记块（根级、没有别名）和被删除后残留的孤立块（根级、没有别名）仍然不是任务。按 ID 读取和任务查询使用同一条规则，查询中写作"有父块或有别名"。转为任务拒绝日记块和任务标签块自身。

## Considered Options

- 一律排除根级块（第二步 #20、#21 的规则）：最简单，但页面无法成为任务，与 Orca"一切皆块"的使用方式相悖。被取代。

## Consequences

- 页面任务按 ADR 0003 成为页面中所有任务的父任务：页面处于将来/也许或等待中时，整页的任务都在搁置子树里。父任务已完成而子任务未完成时如何处理，在第五步讨论。
- 页面打开时，标题处的任务标签与普通块结构相同，状态图标能显示（`docs/spikes/page-task.md`）；标题处的点击在实现后手动检查。
- 孤立块与"用代码建出、没有别名的根级块"在数据上仍无法区分，两者都不是任务（`docs/spikes/tag-operations.md`）。
