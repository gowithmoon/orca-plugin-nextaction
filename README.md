[虎鲸笔记（Orca Note）](https://www.orca-studio.com/orcanote/zh/)的 GTD 任务管理插件（原Task Planner），支持任务创建、下一步行动计算、我的一天、项目、回顾等功能。

## 功能概览

### 任务与捕获

- 用「转为任务」命令把当前块变成任务，或用「创建任务」弹窗随手记下新任务，新任务追加到当天日记末尾，也可以直接在当前块打上任务标签。
- 六种状态：收集箱（任务初始状态）、待开始、进行中、等待中、将来/也许、已完成。
- 以虎鲸笔记的块层级表示父子任务，父任务允许设置“顺序执行”，子任务将按照笔记内的顺序依次进入下一步行动。
- 支持设置重复任务、任务提醒。
- 插件面板里的任何任务卡片都能拖进笔记，生成任务的块引用；按住 `Alt`（`Option`）生成镜像块。

### 下一步行动

插件根据状态、子任务、依赖、顺序执行、开始日期和项目状态，算出此刻能做的任务，按评分排序。评分综合截止日期、开始日期、重要性和紧急度，再按工作量调整；重要性和紧急度会沿父任务和项目继承。

### 我的一天

每天早上可以在任务清单中挑选今天要做的任务，右键加入我的一天，我的一天视图支持三种布局：

- 时间轴：把任务拖到时间轴上排期，拖动调整时间和时长。
- 列表：按优先级评分降序，平铺展示今天要做的任务。
- 四象限：按重要性和紧急度分进四个象限，拖到别的象限会改写对应的值。

### 收集箱与全部任务

- 收集箱：任务初始状态，需要在任务属性面板里逐个澄清，确认哪些要做、哪些放在未来、哪些已经不再需要去做。
- 全部任务：树形结构展示所有任务，支持搜索、筛选、排序、拖动。

### 项目

给块打上项目标签，它就成了项目。项目列表按项目状态（规划中、进行中、暂停中、将来/也许、已完成）分组，显示每个项目的进度，以及它是否逾期、缺少下一步行动或长期无进展。项目详情有三种布局：

- 层级：和全部任务一样，以树形结构展示该项目下的所有任务。
- 看板：按状态或按根任务（项目下的顶层任务）分列，拖动卡片改状态或改父任务。
- 甘特图：按日、周、月显示，拖动横条改日期，画出依赖箭头，标出日期冲突，可以一键顺延后续任务。

### 回顾

按 GTD 每周回顾的顺序逐步检视：收集箱、回看过去、逾期任务、未来 7 天到期、下一步行动、等待中、项目、将来/也许、需要回顾的任务、小结。每一步都有加入我的一天、改截止日期、放弃等快捷操作。任务可以设回顾周期或指定回顾日，到期后出现在「需要回顾的任务」里。

### 任务全景图

以图的形式展示所有任务的关系：项目和父任务分组展示，顺序执行的子任务依次相连，箭头连接线表示依赖关系。点一张卡片会高亮它的上下游任务。你可以在图上通过拖动来设置依赖、删除依赖、切换顺序执行，也可以把任务拖进别的分组（加入父任务或项目）。

### AI

使用虎鲸笔记内置AI功能，当前支持以下操作：

- 拆分子任务：把一个任务拆成若干子任务。
- 提取任务：从所选的块里找出任务，写进笔记并打上任务标签。
- AI 小结：在回顾的最后一步生成本次回顾的小结，可以一键写入今天的日记。

可以在设置中指定一个块作为补充提示词，每次请求都会携带该块及其子块，你可以在这个块里写下你的习惯、偏好以及指令等。

## 安装

### 从插件市场安装

1. 打开 Orca 的插件市场，搜索「今天干点啥」并安装。
2. 在「设置 → 插件」中启用它。

### 下载 zip 安装

1. 在 [Releases](https://github.com/gowithmoon/orca-plugin-nextaction/releases) 页面下载 `orca-plugin-nextaction-v<版本号>.zip`。
2. 解压到用户文档目录下的 `orca/plugins` 中：
   - Windows：`C:\Users\<用户名>\Documents\orca\plugins`
   - macOS：`~/Documents/orca/plugins`
3. 确认解压后的路径是 `orca/plugins/orca-plugin-nextaction/`，文件夹里直接放着 `dist/`、`package.json` 等文件。
4. 重启 Orca，在「设置 → 插件」中启用它。

> [!IMPORTANT]
> 文件夹名必须是 `orca-plugin-nextaction`。Orca 用文件夹名识别插件，插件的设置和数据都按这个名字保存，改名之后就成了另一个插件。

## 快速上手

1. 点编辑器右侧工具栏里的「今天干点啥」按钮，打开插件面板，再点一次就关闭。
2. 在笔记中输入 `/`，选「转为任务」把当前块变成任务，或者选「创建任务」新建一个，也可以直接在块上打上任务标签（默认为“任务”，设置中可以修改）。
3. 常用的「转为任务」「创建任务」「提取任务」可以在 Orca 的快捷键设置中自己绑定。
4. 任务操作菜单在任务块的块菜单里，右键任务标签或右键插件面板中的卡片也能打开。点任务前的状态图标可以直接改状态。

### 设置

在「设置 → 插件 → 今天干点啥」中修改：

| 设置 | 默认值 | 说明 |
|---|---|---|
| 任务标签名 | 任务 | 识别任务的标签。首次启动时按界面语言取「任务」或「Task」 |
| 项目标签名 | 项目 | 识别项目的标签。首次启动时按界面语言取「项目」或「Project」 |
| 日界线 | 5:00 | 一天从这个时刻开始，影响我的一天、逾期和重复 |
| 提醒默认时刻 | 9:00 | 快捷提醒选项（如截止日期当天、提前 3 天）在这一时刻通知 |
| 项目视图默认布局 | 层级 | 层级、看板或甘特图 |
| 我的一天默认布局 | 时间轴 | 时间轴、列表或四象限 |
| 开始日期预览天数 | 0 | 开始日期在 N 天内的任务提前出现在下一步行动中，评分略低 |
| AI 说明块 | 空 | 填一个块编号，每次 AI 请求都带上这个块及其子块 |

> [!WARNING]
> 想改任务标签或项目标签的名字，只能在插件设置里改，不要直接在虎鲸笔记里给这两个标签改名或删除它们。

### AI 的前提

使用拆分子任务、提取任务和 AI 小结之前，先在 Orca 的设置中配置好 AI 对话模型。插件不会自己连接任何模型，也不需要单独的密钥。

## 从源码构建

需要 Node.js 24 和 pnpm 12。

```bash
pnpm install
pnpm build          # 构建到 dist/
pnpm package        # 构建并打包成 release/orca-plugin-nextaction-v<版本号>.zip
pnpm check          # 类型检查、lint、测试、构建
```

`pnpm package` 生成的 zip 里只有一个 `orca-plugin-nextaction/` 文件夹，包含 `dist/`、`package.json`、`icon.svg`、`LICENSE` 和两份 README，可以直接上传到 Releases，或者解压到插件目录。

本地调试时，在仓库根目录建一个 `.env.local`，写上 Orca 的插件目录：

```bash
ORCA_PLUGINS_DIR=/path/to/Documents/orca/plugins
```

然后运行 `pnpm deploy:local`，构建结果会复制到 `orca-plugin-nextaction/` 文件夹中。
